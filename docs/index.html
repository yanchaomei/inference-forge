Install from the source checkout
git clone https://github.com/yanchaomei/inference-forge
cd inference-forge
pip install '.[inference,client]'
inference-forge serve /path/to/Qwen2.5-0.5B-Instruct \
  --served-model-name qwen2.5-0.5b
Connect with a familiar client
from openai import OpenAI
client = OpenAI(
    base_url="http://127.0.0.1:8000/v1",
    api_key="unused",
)
# Text, plain-text chat, and SSE streaming
reply = client.chat.completions.create(
    model="qwen2.5-0.5b",
    messages=[{"role":"user", "content":"Hi"}],
    max_tokens=16, temperature=0,
)
print(reply.choices[0].message.content)
