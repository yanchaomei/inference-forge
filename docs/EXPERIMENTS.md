# 实验说明

## Bootstrap

2026-10-20 的真实权重原型验证包含25项测试、4个并发请求、64 token输出。cached／recompute两模式的128次选定token概率观测通过，最大绝对差约1.59e-5。该轮用于验证运行时与独立验收，不是构造器性能比较。

## 实际 Agent 构造迭代

2026-10-30 的生成调用使用 Codex CLI 与账户可用的 gpt-5.6-sol，固定起点为初版运行时。生成器实际只修改 engine.py 和 server.py，增加批量decode及调度；评测代码保持固定。

调用耗时77.69秒；事件报告input tokens 258104，其中cached input 226560，output 6359。token计数不是费用估算，未将未知美元费用填零。

候选先通过真实参考、缓存、并发流式和原有负例验收，再在同一设备执行固定开发负载。顺序为初版A、候选B、候选B、初版A，每次3个暖运行样本。原始样本和各次中位数见 `results/campaign-20261030.json`。

额外检查候选的批量路径：3、17、31 token的不同前缀，连续4步解码，共12次完整词表logits与独立HF比较，最大绝对误差5.34e-5，已测argmax一致，原始缓存状态保持不变。

该结果说明真实 Agent 修改能够被独立运行验证，并在这个小负载中改进自身初版。只有2次独立执行/实现，尚无广泛任务、多生成种子或生产SLO结论。批量decode是成熟优化，本项目研究的是完整构造过程与执行反馈。

## 重放自动生成的候选

`examples/generated/batched/` 保存本次生成的两个原始源码文件。可在独立 checkout 中替换 `forge/engine.py` 和 `forge/server.py`，再用相同任务执行验收。不要覆盖自己的未提交改动。

公开数据去除了内部机器地址和个人目录；模型、精度、输出长度、来源散列与生成usage保留。模型权重需从官方来源自行准备。
